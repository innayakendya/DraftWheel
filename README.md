# DraftWheel

DraftWheel transforms text files into printable PDFs using a command-line interface.

DraftWheel is a command-line tool that converts simple text files into PDFs with customizable headers and footers.

**Key benefits**

- Automates the process of converting text files into PDFs
- Provides customizable headers and footers
- Does not require a graphical user interface

## Key Features

- Supports text file conversion to PDF
- Allows customization of header and footer content
- Can handle large text files

## Technology Stack

- Python
- ReportLab

## Installation

1. Clone the repository using git clone
2. Install required packages using pip
3. Run the tool using the command-line interface

## Configuration

Configuration is done through command-line arguments and environment variables.
